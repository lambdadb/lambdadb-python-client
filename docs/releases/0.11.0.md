## Scope and compatibility

- Add 33 fixed text analyzer presets, for 49 total. Preserve the original 16 names/order, lowercase SDK validation, server standard default and existing serialization.
- Preserve explicit analyzer names in Qdrant payload schema mapping; unsupported schema options now raise rather than silently disappearing.
- Add optional per-query native reranking with typesafe/jev-1.13.0, default or custom 2–10 criteria, and sync/async model/TypedDict APIs.
- Preserve final score precision and zero, envelope retrievalScore, top-level status/criteria metadata and actual docsUrl hydration. No client-side reordering, provider API keys or fallback execution.
- keyword remains a text analyzer distinct from keyword field type. Nepali/Tamil/Telugu are Lucene extensions. Facets restrictions remain unchanged.
- Python support stays 3.10–3.13; runtime dependency ranges are unchanged.
